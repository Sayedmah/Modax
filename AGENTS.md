# MODAX engineering instructions
Read project_state.json and docs/PROJECT_STATE.md before making changes. Preserve completed workflows. Use small modules and test owner isolation and failure states. Run `python -m pytest -q`, `python -m ruff check backend tests`, `node --check apps/web/app.js`; set MODAX_TEST_GODOT for engine validation. No paid inference in CI. Never execute generated code on the host. Runtime tests are an opt-in dedicated Docker worker with immutable approved image, network disabled and strict limits. No production deployment or merging without explicit authorization. Use a development branch and draft PR. Report unavailable providers/builds honestly.
